# ちいさな迷宮 ダイス版

## ファイル構成

```
index.html              ゲームの画面（HTML）
css/style.css           見た目
data/equipment.xlsx     装備・スキル・ダイスのデータ表（Excelで編集）
js/main.js              メイン（戦闘・お店・イベント・報酬・セーブ・表示）
js/enemies.js           敵（イラスト・ステータス・行動パターン）と階層
js/dice.js              ダイスの出目の集計
js/equipment.js         装備のしくみ（枠・発動順・ダメージ計算の流れ）
js/equipment_fx.js      装備ごとの効果プログラム
js/skills.js            基本行動・パッシブ・行動ボタンの表示
js/skills_fx.js         スキル／魔法ごとの効果プログラム
js/codex.js             図鑑
js/data.js              Excelを読み込んで、効果プログラムとくっつける
js/xlsx-reader.js       xlsxを読むための小さなプログラム（外部ライブラリ不要）
```

## Excelの編集

`data/equipment.xlsx` を編集して、GitHubの同じ場所にアップロードし直すと反映されます（ブラウザを再読み込み）。

- 「装備」シート … 名前・価格・レア度・説明と、茶色の見出しの数値（倍率・回数など）
- 「スキル」シート … 種別・名前・MP・待機ターン・説明・必要条件
- 「ダイス」シート … 名前・表示・出る目・価格・説明
- 1行目の見出しは変更しない（列の順番は入れ替えてもOK）。ID列は変更しない。
- 行の順番がゲーム内の並び順になる。
- 間違いがあると、タイトル画面の下とブラウザのコンソールに注意が出る。

## 新しい効果を作りたいとき

- 装備 … `js/equipment_fx.js` に、表のIDと同じ名前で効果を書く
- スキル／魔法 … `js/skills_fx.js` に、表のIDと同じ名前で効果を書く
- そのあと、Excelの該当シートにIDを同じにした行を足す

## 遊ぶとき・試すとき

GitHub Pages（ブラウザでURLを開く）で動きます。
`index.html` をダブルクリックで開くと、Excelを読めないため動きません。手元で試すときは、このフォルダで
`python -m http.server` を実行して、`http://localhost:8000/` を開いてください。
